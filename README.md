# Marketing Skills

A collection of marketing skills for developing and critiquing campaign ideas, brand positioning, and advertising stories.

## Included skill

### [Marketing Genius](marketing-genius/SKILL.md)

Develop unconventional campaign concepts grounded in human insight and product truth. The skill covers creative exploration, visual storytelling, brand memory, concept critique, and practical testing.

Supporting material includes:

- Campaign case studies and transferable creative questions
- Human stakes and scene-to-line exercises
- Visual storytelling mechanisms
- Research foundations and testing methods

The `marketing-genius` folder contains the complete skill, including its instructions, references, interface metadata, and icon. Keep these files together when sharing or installing the skill.

## Get a copy

With access to this repository and GitHub CLI installed:

```sh
gh repo clone RyanJMcGowan/marketing-skills
```

Start with [the skill instructions](marketing-genius/SKILL.md) to understand its workflow.
